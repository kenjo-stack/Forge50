# Anatomy model attribution

The Forge50 anatomy geometry is adapted from the `anatomy.glb` and `skeleton.glb`
files in [JohanBellander/BodyExplorer](https://github.com/JohanBellander/BodyExplorer/tree/7d04bf3c4de2bd9cb234dd51d7e6857c099afafd/public).

- BodyParts3D, © The Database Center for Life Science (DBCLS):
  [Creative Commons Attribution-ShareAlike 2.1 Japan](https://creativecommons.org/licenses/by-sa/2.1/jp/).
- Z-Anatomy, by Gauthier Kervyn, derived from BodyParts3D:
  [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).

The adapted anatomy data in this directory retains these source attribution
and share-alike terms. Changes: selected visible muscles and skeletal structures,
mesh simplification, coordinate transformation, position quantization and binary
packing. Exercise colors and focus markings are applied at runtime. Source data
and the build process are linked above and in `tools/build-anatomy.py`.

This notice concerns the model data. The viewer is Forge50 code.
