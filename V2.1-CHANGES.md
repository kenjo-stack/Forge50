# Forge50 v2.1 — Readable Exercise Guides

- Increased small text throughout the app and improved muted text contrast.
- Added keyboard-accessible guide tabs: Technique, Muscles, Progress, Alternatives.
- Guide lookup uses stable catalog exercise IDs; renamed catalog entries retain their guide when the ID stays the same.
- Progress shows last completed working sets and links users back to the existing workout-card recommendation.
- Alternatives are drawn from the existing exercise catalog and do not change saved routines.
- Offline service-worker cache includes the new stylesheet; existing schema-2 backups remain compatible.
- No unverified exercise images or muscle illustrations are included.
- Cycling logging and rotating routine remain unchanged.

Run `node tests/store.test.cjs` and `node tests/browser.test.cjs` with Playwright/Chromium installed.
