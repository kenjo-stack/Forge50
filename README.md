# Forge50 v1.5 — Text Exercise Guides

This Forge50 build keeps the existing workout programme, progressive overload, exercise logbook, smart rest timer, PWA/offline support and integrated Guide buttons.

The exercise guides are now text-first cards for every exercise in the programme. Each guide explains the training focus, primary and secondary muscles, setup, execution, form checks, common mistakes and equipment. No exercise illustrations or external image files are required, so the guides remain lightweight and fully offline.
