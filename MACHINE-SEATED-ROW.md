# Forge50 2.12.1 — chest-supported machine row

Adds **Machine Seated Row (Chest-Supported)** as a separate Back exercise. It appears in same-movement swaps for rows when **Resistance machines** is available, and in the Back guide's alternatives. The existing dumbbell bench-row demonstration remains a separate exercise.

The guide covers the upright chest pad, seat and foot-support setup, neutral or horizontal grips, pulling towards the lower ribs, and a controlled return. Its muscle illustration uses the mid-back map. Its own looping GIF plays in Demo and the guided workout, and is cached after viewing online for later offline use.

Swaps keep completed sets on the original exercise and transfer only unfinished sets. The replacement starts with an empty machine load. Saved routines, workout order, existing exercise IDs and history use the existing storage and swap behaviour.

## Update on a phone

Open Settings → Check for update → Update now. In a Back workout, tap Swap beside a row, then choose Machine Seated Row (Chest-Supported). If it is missing, open Refine choices and include Resistance machines. Open Guide → Demo to view the animation.

## Reference

The exercise is based on the user's photograph of a Matrix seated row with an upright chest pad and rigid lever handles. Matrix's official Aura Seated Row description: https://uk.matrixfitness.com/eng/strength/single-station/g3-s31-seated-row

The new demonstration is an original ImageGen anatomical illustration assembled into a looping GIF. It depicts a fixed seated torso against an upright chest pad, pulling attached handles from an extended reach towards the lower ribs and returning slowly. The primary mid-back region is orange; assisting muscles are blue. No existing exercise GIF is reused.
